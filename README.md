# 우리 모둠 데이터 탐구 보고서

> 가상 자료 · 기능 연습 예시 · 공개 검토 확인본

작성: Yul율

## 1. 탐구 질문
시간과 날씨가 주어지면 대여량을 얼마나 잘 추정할 수 있을까?

## 2. 데이터 출처와 범위
- 출처: 수업용으로 생성한 공공자전거 가상 자료
- 주소: 외부 출처 없음
- 이용 조건: 수업에서 활용·수정 가능. 실제 도시의 관측 통계로 인용하지 않기.
- 범위: 가상 도시, 2024-04-01~2024-04-30, 720시간. 오류와 중복을 넣은 정제 연습용 723행.
- 읽은 행 723 → 정제 후 720

## 3. 정제 이유
초기 데이터의 결측치와 이상치를 제거하여 분석의 정확성과 모델의 신뢰성을 높이고자 했습니다.

## 4. 그래프와 해석

### 요일구분별 대여량 개수 비교
요일구분별 대여량은 주말보다 주중에 높게 나타났으며, 특히 금요일에 가장 많았습니다. 이는 출퇴근 수요와 관련이 있을 것으로 보입니다.

사용 720행 / 빈값 제외 0행. 범주별 기록 수를 함께 확인하세요. 합계와 평균은 다른 질문입니다.

### 기온 × 대여량: 함께 변할까?
기온이 상승함에 따라 자전거 대여량도 증가하는 경향을 보였습니다. 20도 이상에서는 대여량이 더욱 활발해지는 패턴이 관찰됩니다.

유효 718행 중 718개 점 표시(1,500개 초과 시 고정 무작위 표본). 관계는 원인의 증거가 아닙니다.

### 일별 대여량 평균의 변화
일별 대여량 평균은 주중과 주말에 따라 명확한 패턴을 보였으며, 특정 날짜에 급격한 증감이 있었습니다. 이는 날씨 변화나 특정 이벤트와 관련이 있을 수 있습니다.

사용 719행 / 날짜·값 누락 제외 1행. 관측값 없는 기간은 선으로 이어 붙이지 않습니다.

## 5. 머신러닝
과제: 회귀 / 정답: 대여량

입력: 시간, 기온, 습도, 풍속, 강수량, 요일구분, 날씨

시간순 분리(서로 다른 시점 기준 앞 약 80% / 뒤 약 20%), 학습 575행, 시험 144행

| 방법         |      MAE |      R2 |
|:-------------|---------:|--------:|
| 평균 기준    | 116.656  | -0.0001 |
| 의사결정나무 |  43.1017 |  0.8529 |

AI의 평균절대오차가 기준보다 작았습니다.

우리가 개발한 모델은 시간과 날씨 변수를 활용하여 자전거 대여량을 예측하는 데 어느 정도의 성능을 보였습니다.

## 오류에서 배운 점
모델이 예측에 실패한 사례들을 분석한 결과, 특정 비정상적인 상황(예: 급작스러운 기상 변화)에 대한 예측력이 부족함을 발견했습니다.


## 결론
시간과 날씨 데이터는 자전거 대여량 예측에 유의미한 영향을 미치는 것으로 나타났습니다.


## 수치 근거
자세한 분석 수치는 보고서 내 그래프와 모델 평가 섹션에서 확인할 수 있습니다.


## 한계
이 분석은 가상 데이터와 제한된 기간에 기반하므로, 실제 환경에 직접 적용하기 위해서는 추가적인 검증과 더 많은 실측 데이터가 필요합니다.


## 다음 질문
대여량에 영향을 미치는 추가적인 요인(예: 공휴일, 이벤트, 주변 시설)은 무엇일까? 예측 모델의 정확도를 더욱 높일 수 있는 방법은 무엇일까?


## AI 사용과 확인
생성형 AI를 활용하여 코드 작성 및 분석 가이드를 얻었으며, 모든 결과와 수치는 직접 검토하고 확인했습니다.

## 평가 시 주의
이 결과는 탐색용 홀드아웃 평가입니다. 전체 자료의 그래프를 보고 입력을 선택했으므로 독립된 최종 성능 인증이 아닙니다.

같은 시험 결과를 보고 입력이나 나무 깊이를 반복 조정하면 시험에 맞춘 모델이 됩니다. 다시 평가하려면 별도의 미사용 자료가 필요합니다.

HTML 그래프에는 그래프용 값이 들어 있습니다. 개인·민감 자료는 공개하지 않습니다.
